Vision Tracker Android project


Це вихідний Android Studio-проєкт, а не готовий APK.

Як зібрати APK:
1. Встановіть Android Studio на Windows/Mac/Linux.
2. Розпакуйте архів VisionTrackerAndroidProject.zip.
3. Android Studio -> Open -> виберіть папку VisionTrackerAndroidProject.
4. Дочекайтеся Gradle Sync; за потреби погодьте встановлення Android SDK 35.
5. Build -> Build Bundle(s) / APK(s) -> Build APK(s).
6. APK буде у app/build/outputs/apk/debug/app-debug.apk.
7. Перенесіть APK на Android телефон і відкрийте його для встановлення. Якщо Android запитає, дозвольте встановлення з цього джерела.

Застосунок працює офлайн; прогрес зберігається локально в WebView. Не видаляйте застосунок/дані, якщо хочете зберегти прогрес.
